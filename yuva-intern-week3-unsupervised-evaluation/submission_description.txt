This project implements an end-to-end workflow for unsupervised learning and machine-learning model evaluation using Python and Scikit-learn. It uses the Scikit-learn Breast Cancer Wisconsin Diagnostic benchmark dataset, which contains 569 observations and 30 numerical predictors. The dataset is used only for educational experimentation and is not intended for medical diagnosis or clinical decision-making.

For unsupervised learning, the diagnosis label is excluded from the feature matrix before clustering. The numerical predictors are standardized, and K-Means and Agglomerative (hierarchical) clustering are compared for cluster counts from two to six. The silhouette score is used to assess cluster separation and compactness. Adjusted Rand Index is calculated only after fitting as a post-hoc comparison against the dataset labels; it is not used to train the clustering algorithms or select the number of clusters. Principal Component Analysis (PCA) reduces the standardized 30-feature representation to two components for visualization, and the report explains the proportion of variance retained by this projection.

For supervised model evaluation, the dataset is divided into stratified training and test sets. Logistic Regression and Random Forest are tuned using five-fold StratifiedKFold cross-validation and GridSearchCV, with ROC-AUC as the selection metric. Final performance on the held-out test set is documented using accuracy, malignant-class precision, malignant-class recall, F1-score, ROC-AUC, and confusion matrices. The project includes actual measured result tables, selected hyperparameters, code examples, figures, a Jupyter notebook, a reproducible Python script, saved model pipelines, and a Word report. The interpretation compares the models' trade-offs instead of relying on a single score and clearly states the limitations of the benchmark and split-based evaluation.
